# 호그와트 상황별 의상·유저 시점 CG

기준 main: `f86516fe0fde8378cc7cb30e6dc9e32c52260528`. 검수한 새 이미지 137장 모두 세로이며, 기존 얼굴·피부톤·나이·체형을 기준으로 제작했다. 132장을 활성 연결하고 교체 전 버전 5장은 함께 보존한다. 이 기록은 제작 및 기능 검수 결과다. 사용자가 새 외형을 별도 승인했다고 주장하지 않는다.

## 실제 연결된 파일

- 새 기본 초상 20장: 기존에 그림이 없던 성인 여성 조연 10명의 기본/미소.
- 무도회 예복 대표 이미지 25장. 헤르미온느, 파르바티·파드마, 초 챙 포함.
- 퀴디치 경기복 대표 이미지 11장과 같은 옷으로 빗자루에 탑승한 비행 CG 11장.
- 여성 학생·방문학생·교직원·성인 조연의 개별 친밀 장면 CG 44장.
- 말포이를 포함한 여성 학생·방문학생 21명의 유저 시점 무도회 춤 CG 21장. 기준 이미지 생성이 차단된 로밀다 1명은 미완료다.

활성 의상 36장, CG 76장, 기본 초상 20장이다. 서로 다른 여성 45명이 유저 시점 친밀 CG를 갖는다. 헤르미온느는 춤 CG가 있으며 일반 도서관 CG는 미완료다. 장면은 옷을 입은 춤·대화·데이트·내민 손 등 비노출 장면이다. 유저의 얼굴·성별은 고정하지 않았다.

추가 지시를 반영해 춤 4명 제한을 해제했다. 말포이의 도도한 비대칭 웃음, 안젤리나의 활짝 웃음, 지니의 장난스러운 웃음, 루나의 몽롱한 시선, 팬지의 코/눈썹 연기, 페넬로페의 발걸음에 집중하는 시선 등 인물별 표정·동작을 다르게 제작하고 개별 확인했다. 파르바티·파드마·초 챙도 기존의 비슷한 미소/손잡기 구도를 새 버전으로 교체했다. 모든 대사 감정에 대응하는 새 표정 세트가 추가된 것은 아니다. 개별 춤 CG의 연기를 구분한 작업이며 의상 스프라이트는 대표 표정 fallback을 사용한다.

드레스는 색·소재·넥라인·장식에 개별 설계를 적용했다. 형태가 겹치던 두 벌만 조정했다. 크래브는 닫힌 칼라/불투명 녹색 벨벳/은색 단추/박스플리츠로 말포이의 투명 소매/은빛 덩굴 자수와 구분한다. 라벤더는 장밋빛 태피터/짧은 퍼프 소매/큰 허리 리본/단일 스커트로 헤르미온느의 분홍 쉬폰 러플과 구분한다. 얼굴·나이·피부·체형은 유지하며 수정된 드레스와 춤 CG가 같은 옷을 사용한다.

실파일 목록·크기·SHA-256·컷별 검수 항목은 [에셋 매니페스트](hogwarts-occasions-assets.json)에 있다. 스프라이트는 주로 1024×1536, 장면 CG는 948×1659이며 전부 높이가 폭보다 크다. 캐릭터 이미지는 투명 배경, CG는 배경을 포함한다.

## 장면과 저장 연결

`looks.js`가 실제 등록된 의상과 CG만 선택한다. 예복의 별도 표정이 없으면 같은 예복의 대표 컷을 사용한다. 퀴디치 관중은 자동으로 경기복을 입지 않는다. 방을 옮기면 기본 복장을 적용하며, 명시적인 의상 지시가 있으면 그 지시를 따른다. 원래 사용자 표정·외형·의상 편집은 보존한다.

모델에는 실제 CG의 장소와 의상 목록을 전달한다. 로맨스 CG는 현장에 해당 인물이 있고 `cgPartner: "player"`, `cgConsent: "mutual"`인 응답에만 표시한다. NPC 파트너가 있는 춤 장면에는 유저 CG가 표시되지 않는다. 스트림의 앞부분에 CG 키가 먼저 와도 최종 파트너 정보를 확인하기 전에는 표시하지 않는다. 비행 CG는 경기복과 실제 비행 메타데이터를 함께 요구한다. 사용자 지정 얼굴이 내장 CG의 기준 얼굴과 다르면 해당 CG를 표시하지 않는다.

실제 표시한 대사와 플레이어 입력에 착장·CG 스냅샷을 저장한다. 기록 이동/종료, 저장·재접속, 대기 중 대사의 의상, 신규 필드가 없는 옛 저장을 검사했다. 사용자 저장을 초기화하거나 과거의 RP 결과를 덮어쓰지 않는다.

크리스마스 무도회 날짜를 1994-12-25로, 시각 배경을 무도회장으로 연결했다. 대연회장이라는 실제 장소는 유지한다. 파틸 자매·초 챙 등 누락된 참가자를 포함하며, 기본 동행은 헤르미온느–크룸, 파르바티–해리, 파드마–론, 초 챙–세드릭, 지니–네빌이다. 현재 RP에서 바뀐 관계는 그 경위를 따르게 한다. 원작 사건 433개 ID와 기존 진행 상태를 보존한다.

최초 129개 및 추가 23개, 총 152개 파일 계획 중 다음 15개는 제작되지 않았다. 완성 목록·CG 목록에 빈 파일이나 임의의 대체 얼굴을 넣지 않았다.

- 로밀다: 기본/미소 초상, 예복, 개별 CG, 춤 CG 5개.
- 알렉토: 기본/미소 초상, 개별 CG 3개.
- 해리: 예복, 경기복, 비행 CG 3개.

- 조지: 경기복, 비행 CG 2개.

기준 초상/의상/개별 CG 요청은 built-in imagegen의 출력 단계에서 `moderation_blocked`(`other`)로 두 번 실패했다. 도구가 세부 이유를 제공하지 않았으므로 원인을 추정하지 않는다. 기준 이미지가 필요한 후속 컷은 실행하지 않았다. 다른 모델·CLI로 우회하지 않았다. 해당 인물은 기존 기본 이미지가 있다면 그 이미지를 유지한다.

## 제작 및 검증

기본 도구는 built-in imagegen이다. seed와 내부 모델 값은 도구가 노출하지 않는다. 원본 PNG, 정확한 프롬프트와 참조, 도구 결과, 검수 기록은 별도 로컬 제작 폴더 `PANDORA_gen/studio-output/hogwarts-occasions-20261118/`에 보존했다. 최신 `jobs-v3.json`, `jobs-extension-v3.json`, `plan-v3.json`, `records/batch-000-hermione.json` 및 `batch-001`~`batch-024`가 재현 근거다. 최초 계획과 기록도 보존한다.

원본 PNG에서 WebP로 무손실 변환 후 디코딩된 RGBA 전체 바이트가 같음을 확인했다. 원본·기존 에셋·불채택 시안은 삭제하거나 덮어쓰지 않았다. 컷별 전체 크기 확인 및 머리/눈/피부톤/나이/체형/의상/손/프레이밍 검수표를 작성했다. 스프라이트 쌍 48개의 기계 판정은 PASS 37개, OUTLIER 11개다. OUTLIER는 원본과 대상의 전체 크기 확인 및 의도된 의상색·머리 정돈 변화 기록을 완료했으며, 기계 판정을 PASS로 바꾸지 않았다. 얼굴 표정의 미세한 일치나 사용자의 취향을 자동 검사가 보장하지는 않는다.

최종 로컬 검사:

- Node 회귀 검사 25개 모두 통과. 실제 파일 해시, 실제 WebP 크기, 세로 비율, 137개 보존 파일/132개 활성 파일과 76개 CG, 춤 대상 21명을 검사한다.
- 추가분 포함 Chromium 데스크톱/모바일 60/60, WebKit 모바일 31/31 통과.
- 화면 증거에서 직접 응답을 넣는 검사 준비가 이전 선택지를 남기던 문제를 발견했다. 실제 입력 경로처럼 정리하고 CG 로드/등장 애니메이션 종료를 기다리도록 검사만 수정했다. 두 엔진의 해당 모바일 검사 12/12씩 재통과했고, 선택지 박스가 하나인지도 검사한다.

- 의상 갱신이 다른 인물의 기존 표정을 초기화하던 구현 중 회귀를 발견해 수정했고, 기존 화자/표정 검사도 다시 통과했다.

브라우저 응답은 모두 로컬 픽스처다. 실제 AI 발화의 장기 품질과 사용자 원본 저장에서의 실플레이는 검사하지 않았다. 실제 모델 호출·클라우드 쓰기는 0회다.
