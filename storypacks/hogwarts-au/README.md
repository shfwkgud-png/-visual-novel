**작업 상태 (2026-11-17): 판도라 SFW 플레이에 통합 / 198장·433비트 관리 / 52개 개별 교내 장면 / 22개 주요 사건 연계 / 124개 비공개·학교 밖 사건은 독립 진행.**

## 1. 조사 범위와 사실 확인 한계

- **원작 7권의 소설 원문 전문을 직접 읽은 작업은 아니다.** 사용자 제공 원문 전자책을 찾지 못했다.
- Harry Potter Lexicon의 각 권 1장~마지막 장의 가이드, 연표, Harry Potter 공식 자료의 호크룩스와 딱총나무 지팡이 설정을 대조했다.
- 원작 문장을 복제하지 않았다. AI가 장면을 연출하고 세계 상태를 검증할 수 있는 짧은 사실 단위로 직접 재서술했다.
- 원작의 묘사·인물의 내면·세부 동선까지 문장 단위로 모두 포괄한 백과사전이라는 주장은 하지 않는다.
- 원작 소설이 최우선이다. 영화에서만 추가된 사건은 게임 정사로 자동 채택하지 않는다. 실제로 6권 탑 사건에서 벨라트릭스의 영화판 출연은 데이터에서 제거했다.

**검토 자료:** [원작 1~7권 장별 가이드](https://www.hp-lexicon.org/source/the-harry-potter-novels/), [주요 연표](https://www.hp-lexicon.org/master-timeline/), [호크룩스의 역사](https://www.harrypotter.com/features/history-of-voldemorts-horcruxes), [딱총나무 지팡이](https://www.harrypotter.com/features/everything-we-know-about-the-elder-wand). 각 권 파일 안에도 개별 출처 URL이 있다.

## 3. 재해석의 고정 규칙

**호그와트의 이름, 위치, 네 기숙사, 교수진, 학생 생활과 7년 학제는 그대로다.** 새 대학교를 만드는 게 아니다. 입학 시점만 18세 이상으로 변경한 별도의 평행 연속성이다.

- 해리·론·헤르미온느와 말포이는 1991년부터 성인 신입생이다. 나이/외형에 따라 일곱 번 에셋을 교체하지 않는다.
- 말포이는 **여성 드레이코 말포이 AU**다. 슬리데린 출신, 루시우스와 나시사의 자녀, 해리와의 경쟁, 6권의 암살 임무, 지팡이 충성 관계는 유지한다.
- 4권 트리위저드 시합의 원작 17세 제한을 그대로 적용할 수 없으므로 지원 요건을 5학년 이상으로 바꾼다. 4학년 해리는 여전히 비정상적으로 추가 선발된다.
- 7권의 더즐리 혈연 보호와 마법부의 미성년 마법 제한은 성인 입학 설정과 충돌하므로 별도 AU 규칙으로 해석한다.
- 마법이 효과를 발휘하는 원리, 학교를 둘러싼 권력 구조, 포터 부부의 과거, 볼드모트의 호크룩스와 덤블도어의 비밀은 장부의 원작 인과를 우선 유지한다. 출생연도와 성인 입학 규칙이 문자 그대로 일치한다고 주장하지 않는다.
- 원작의 배경 설정 외에 불필요한 새로운 마법기관이나 대학 시스템을 추가하지 않는다.

## 4. 게임 설계의 핵심 원칙

### 독립 사건 시계

세계관 사건은 사용자의 매 채팅 메시지마다 자동으로 넘어가지 않고, 게임에서 **학사 일정·날짜·실제 플레이 사건 진행**에 따라 순서대로 확정해야 한다. 플레이어가 어떤 사건을 목격하지 못하더라도 해당 사건은 세계에서 일어날 수 있다. 다만 플레이어를 사건 현장으로 강제 순간이동시키지 않는다.

### 세계의 진실과 플레이어의 지식 분리

- **public:** 학교나 마법사회가 공개적으로 알 수 있는 사실.
- **local:** 실제 장소에 있어야 목격할 수 있는 사실.
- **private:** 특정 인물만 직접 아는 사실.
- **gm:** 과거부터 참이었지만 아직 반전으로 남겨야 할 비밀. AI는 세계 상태를 결정하는 용도로만 사용한다.

예컨대 4권의 가짜 무디가 바티 크라우치 2세라는 사실, 6권 덤블도어와 스네이프의 비밀 약속, 7권 해리의 영혼 조각은 누가 무엇을 입증했는지에 따라 다르게 알려진다. 학생이 미래의 원작 줄거리를 무조건 아는 설정으로 진행하지 않는다.

### 정사가 꺾이면 분기한다

- 3권에서 페티그루를 사로잡으면 4권의 **기존 방식 묘지 부활**은 막힌다. 다른 충복이 가능할지는 대체 세계선에서 별도 인과 판정으로 해결한다.
- 6권에서 사라지는 장롱을 차단하면 죽음을 먹는 자의 **원작 방식 학교 침입**이 자동으로 성립하지 않는다.
- 6권 말포이의 무장해제를 막으면 딱총나무 지팡이의 충성권을 원작처럼 자동 승계하지 않는다.
- 7권에 나기니와 독립 호크룩스가 남아 있다면 볼드모트의 완전한 소멸을 확정할 수 없다.

바뀐 사건의 후속 사건은 **pending**으로 보류한다. 새로운 인과가 확보되지 않았는데 억지로 정사 결과를 발생시키면 안 된다.

### 비밀과 선택의 분리

불사조 기사단, 죽음을 먹는 자, 마법부, 학교 교직원은 각자의 정보와 이해관계로 행동한다. 일반 학생 유저가 어느 편에 속하든 원작 등장인물의 역사와 세계 자체가 플레이어를 중심으로 재작성되지는 않는다. 선택은 학년 진행 및 핵심 인과에 실질적 영향을 미칠 수 있어야 한다.

## 5. 게임 통합 상태와 검증 (2026-11-17)

**게임 진입:** 판도라 메뉴에서 호그와트 스토리를 선택한다. 캐릭터·배경 이미지가 없어도 SFW 플레이 가능하지만 AI 대화 모델 공급자/API 설정은 기존 판도라를 따른다.

- **입학식:** 성인 신입생 설정 → 분류모자 → 덤블도어의 인사 → 만찬 → 반장 인솔 → 기숙사별 출입 → 공용실. 당연한 연설에 별도 선택을 강요하지 않는다.
- **시간·장소:** 실제 수면·이동·수업 등 본문에 확인된 경과를 달력에 반영한다. 여러 날을 건너뛸 때는 사용자 요청도 확인한다. 입학 자동 장면 사이에는 자유 입력이 가능하며, 개입하면 남은 고정 연출 대신 현재 행동에서 RP를 이어간다. 기숙사 출입은 각 기숙사 환경에 맞는 문지기 반응을 거친다.
- **198장 분류:** 전체 장의 시기·사건·접근·상호작용을 기록한다. 52개 장은 고유한 도입과 실제 개입 선택이 있고, 22개 장은 주요 사건에 결합, 124개 비공개·교외 장면은 직접 목격하지 않는 세계 뒤편 사건으로 실행한다.
- **433개 사건:** public/local/private/gm 접근성, 정사·변경·미해결·불발 상태를 분리한다. 비공개 정보는 유저 시점으로 자동 공개하지 않는다.
- **분기:** 1권의 교수 사전 신고, 3권 페티그루 구금, 6권 장롱 침입 경로 봉쇄, 6권 지팡이 무장해제 차단은 선행 선택·증거가 필요하다. 인과가 무너지면 이후 부활·천문탑·지팡이 관계 및 최종 전쟁 결말을 원작대로 강제 복원하지 않는다.
- **엔딩:** 정사 승리와 인과가 달라져 미확정인 대체 세계선 결말을 구분하고, 저장/재개 시 플레이어가 한 행동과 인물 반응을 보존한다.
- **비주얼:** NSFW 제외. 이미지 에셋은 외부에서 추가·교체 가능.

**테스트:** canon.test.js, tests-hogwarts-time.js, tests-hogwarts-world.js, tests-hogwarts-scenes.js, tests-hogwarts-chapters.js, tests-hogwarts-branches.js, tests-hogwarts-outcomes.js, tests-browser.js. GitHub Actions에서 Node 회귀와 Playwright Chromium·WebKit 브라우저 흐름을 검증한다.

**2026-11-18 RP 결과 연결:** 기존 상태 기록관이 표시된 본문에서 실제 결과와 근거를 추출한다. 최초 선택은 의도이며, 최종 관계·행동·원작 개입은 실제 장면의 결과를 따른다. 자유 입력도 장부의 알려진 사건과 세계 상태 키를 변경할 수 있고, 변경된 선행조건의 후속 사건은 원작대로 강제 복구하지 않는다. 결과와 사건 장부는 저장 전에 함께 반영된다. 근거가 없거나 이미 확정된 과거를 덮어쓰려는 결과는 적용하지 않는다. 산문의 의미 판정은 여전히 모델에 의존하며, 근거 문자열 대조가 별도의 의미 검증 모델을 뜻하지는 않는다. 브라우저 검증은 외부 AI를 차단한 응답 픽스처이며 실제 AI 장기 플레이를 대체하지 않는다.

**2026-11-18 인물 말투:** 등록된 153항목(별칭·집단·비언어 생물 포함)에 짧은 말투와 상대·감정·시점에 따른 연기 기준을 적용했다. 기존에는 123항목이 같은 공통 성격 설명을 사용했다. 헤르미온느는 빠른 설명과 서툰 다정함, 론은 툭 나오는 농담, 스네이프는 절제된 빈정거림, 엄브리지는 공손한 통제처럼 인물별 리듬을 구분한다. 친밀도가 낮다는 이유로 일괄 존대·냉소를 적용하지 않는다. 다프네·시어도어처럼 발화 자료가 적은 인물은 과도한 팬 해석을 고정하지 않고 장면에서 확인된 태도를 따른다. 동물과 비언어 생물에게 인간 대사를 부여하지 않으며 별칭은 같은 인물의 말투를 유지한다.

말투는 `story.js`의 인물별 연기 지침이며 원작 대사의 인용문이나 공식 번역 화법의 전수 분석을 뜻하지 않는다. 근거 범위는 기존 캐릭터 정의·cast·장별 사건 장부와 사용자 방향이다. 6명 초과 장면에서도 축약 카드에 핵심 말투를 남긴다. 과거의 잘못된 어조보다 현재 카드를 우선하되 실제 사건과 관계는 보존한다. 인물 성격을 직접 고친 사용자 편집은 축약 카드에서도 우선하며, 구형 원본 카드에서 이미지만 바꾼 편집에는 새 기본 말투를 상속한다. 검증은 카드 범위·요청 프롬프트 전달·편집 호환성 검사이며 실제 모델의 모든 발화를 보증하지 않는다. `tests-hogwarts-voices.js`와 브라우저 요청 검사로 확인한다.

**완성도 구분:** 198개 장 모두 일정을 갖지만, 198개 모두를 주인공의 시점으로 보여 주는 것은 아니다. 직접 접근 가능한 52개는 개별 도입·선택을 수작업으로 보강했다. 언어 모델의 개별 발화 품질, 플레이어의 모든 자유 행동, 장시간 실제 세션의 주관적 몰입도까지 전수 검증한 것으로 주장하지 않는다.
